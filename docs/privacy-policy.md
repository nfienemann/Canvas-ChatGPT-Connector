# Development privacy notice

This local release operates with fictional records. It is not a published policy
for a production student service.

The service has no advertising, academic-record sales, sponsored rankings or
model-provider inference calls. Authenticated tool results go to the requesting
MCP client. Course text, grades and credentials are not intentionally logged.
See the data-flow inventory for the exact current record categories and limits.

Disconnect removes active connection records and disables queued work. Remote
revocation is reported separately. It cannot remove copies in previous ChatGPT
conversations, downloads or independent provider records.

Before a real pilot, publish the actual operator, contact, region, recipients,
retention schedule, deletion/export procedure, lawful arrangements and applicable
workspace/provider controls. The proposed durations in the specification are not
proof that an unattended production retention system has been deployed.
