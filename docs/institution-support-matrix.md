# Institution support

| Institution | Registry status | Access proof | Student claims |
|---|---|---|---|
| Synthetic University | unsupported (fictional fixture) | Mock provider only | Local demonstration only |
| Rowan University | candidate | Historical owner-only technical test in a private operator instance | Does not establish current or permanent Rowan approval, endorsement, institutional OAuth approval, or general student support |
| Other institutions | unregistered | None | Unsupported until reviewed |

Identical numeric IDs are separated by connection and course. That implementation
property is not evidence that two actual institutions have approved access.

The private test records technical behavior only. Neither a successful connection
nor this public registry attests to current institutional authorization. Any
separately granted permission is limited to its stated scope and duration and
must be reverified before use; it is not permanent or transferable to other users.

Rowan's [official Canvas page](https://irt.rowan.edu/service-catalog/teaching/lms/)
links to `https://canvas.rowan.edu`. A `personal_testing` entry in a private
operator registry restricts the software to the personal profile. That software
setting does not grant Rowan's permission, change the published support list, or
provide an OAuth key for other students.
