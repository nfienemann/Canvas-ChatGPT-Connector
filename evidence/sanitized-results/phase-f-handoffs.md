## A–F integration

A single synthetic assignment went through the Phase A coursework import path and Phase B criterion assessment. A Phase C material change opened a new episode. The integration test issued its Phase D forecast and study plan, generated Phase E equipment and timing conditions, and saved the revised Phase F packet. The later packet retained the old response as historical. The receipt bundle contains both packets, the actual reconciliation receipt and the linked forecast, plan and Phase E step identities.

## Verification and boundaries

The canonical ZIP passed 396 package checks and 15 negative controls. Standalone fixtures passed 254 checks and 12 negative controls. The broad regression run passed 313 tests, with nine opt-in host cases skipped. The release host journey passed separately. The final targeted run passed 60 tests with two opt-in host cases skipped. The test populations overlap. Ruff passed on the changed Python paths.

An intermediate native run correctly refused export after the working-tree basis schema changed between serving processes. The release run prepared a fresh packet and verified recovery against its own stored basis and actual exported bytes. Final targeted tests also exercised byte-identical aliases on an open remediation item and original-subject response state on archived packets.

The release uses a dirty working tree on base commit `5bd086356e730b01b5a9f1be9de106446ef049c6`. Exact final and native source fingerprints are in `bindings.json` inside the receipt ZIP. The 12-file implementation patch was applied to a temporary reconstruction of the Phase E base and compared to the delivered text. Reproduction instructions are in the Phase F benchmark README.

The default path saves and exports locally. Optional file and delivery operations require a configured destination-authorizing adapter. The downloadable-file test created and verified an actual local Markdown file. The delivery test used a synthetic inbox. Production deployment, installed ChatGPT acceptance, a real teammate destination and the repository-wide full suite remain unverified.
